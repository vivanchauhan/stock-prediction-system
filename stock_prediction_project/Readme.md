# Stock Market Prediction

A machine learning project that predicts stock prices using historical data.

## Features
- Fetches real stock data from Yahoo Finance
- Uses Random Forest and other ML models
- Interactive web interface
- Predicts future stock prices

## How to Run
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly

## Models
- Random Forest
- Gradient Boosting
- Ridge Regression

Made for college major project.
